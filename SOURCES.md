# Sources and methodological basis

The application is based on the supplied DCIFM prototype and the research concept developed for the project.

## User behavior / recommendation modeling
Gao et al., "Learning to Recommend with Multiple Cascading Behaviors."
https://arxiv.org/abs/1809.08161

He et al., "A Survey on User Behavior Modeling in Recommender Systems."
https://arxiv.org/abs/2302.11087

## Object detection
Ultralytics YOLO documentation:
https://docs.ultralytics.com/modes/predict

The project uses YOLO as a visual object/context branch. It does not treat generic object detection as psychological or identity inference.

## Research limitation
The supplied prototype documentation correctly distinguishes model confidence from validated accuracy and notes that generic pretrained YOLO weights are not a project-specific validation dataset.

The synthetic master dataset in this project is intentionally constructed for controlled model testing. It must not be represented as real consumer evidence.
