# Models

This directory is reserved for downloaded or locally supplied model weights.

Preferred visual model:
- yolov8s-worldv2.pt

Fallback visual model:
- yolov8n.pt

The application can download weights through Ultralytics when internet access is available. Model weights are not bundled in this ZIP because they are large binary files and may be subject to their own distribution terms.

The identity classifiers are trained in memory from the supplied synthetic dataset at application startup.
